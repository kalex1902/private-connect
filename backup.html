Настройка T-Cloud Backup

Запустите приложение, войдите в аккаунт и выберите папку для автоматического резервного копирования.

Windows

Распакуйте архивНе запускайте программу прямо из ZIP.
Запустите приложениеОткройте файл Daotta.Desktop.exe.
Войдите в аккаунтВведите логин и пароль T-Cloud.
Добавьте папкуВыберите папку, резервную копию которой нужно создавать.

Linux

Откройте терминал в распакованной папке.

Запуск приложения
chmod +x Daotta.Desktop
./Daotta.Desktop console

После запуска выполните:

Вход и добавление папки
login
add "/путь/к/папке"
list

Вместо /путь/к/папке укажите настоящую папку.

Проверка

Папка должна появиться в списке. После этого оставьте приложение запущенным — новые файлы будут копироваться автоматически.

Если появилась ошибка, сохраните её текст и обратитесь к спонсору или аудитору, который вас пригласил.
