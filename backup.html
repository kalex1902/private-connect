Установка T-Cloud Backup, вход в аккаунт, добавление папки и проверка синхронизации на Windows и Linux.

Важно: публичная ссылка на установочный файл не подтверждена. Используйте только архив, который вы получили напрямую от администратора T-Cloud. Не скачивайте программу со случайных сайтов.

Быстрый маршрут

Если устанавливаете впервые, идите по порядку. На повторном запуске обычно достаточно открыть программу и проверить статус.

1. Подготовиться2A. Windows2B. Linux3. Первая копия4. Проверка

Что подготовить

  • Установочный архив для вашей системы.
  • Логин и пароль T-Cloud.
  • Папку, которую нужно копировать.
  • Стабильный интернет без VPN-фильтрации.
Хороший выбор для начала

Создайте тестовую папку с 2–3 небольшими файлами. После проверки добавьте основную папку.

Не выбирайте целиком системный диск, папки Windows/Linux, каталоги программ, ключи SSH или хранилища паролей.

Windows

Подходит для Windows 10 и 11. Имена кнопок в конкретной сборке могут немного отличаться; консольные команды ниже взяты из меню самого клиента.

Распакуйте архивСоздайте постоянную папку, например C:\TCloudBackup, и полностью распакуйте туда архив. Не запускайте программу прямо из ZIP.
Проверьте источникВ папке должен находиться исполняемый файл клиента. В использовавшейся сборке он называется Daotta.Desktop.exe. Если имя другое, не переименовывайте файл — уточните название у администратора.
Запустите программуДважды щёлкните по исполняемому файлу. Если интерфейс не открылся автоматически, оставьте программу запущенной и откройте в браузере http://localhost:5000.
Войдите в T-CloudВведите логин и пароль, полученные от администратора. Пароль не нужно отправлять кому-либо в сообщениях или вставлять в команды.

Надёжный вариант через консоль

Откройте PowerShell в папке программы: кликните по адресной строке Проводника, напишите powershell и нажмите Enter.

Запуск консоли
.\Daotta.Desktop.exe console
Команды внутри T-Cloud
login
add "C:\Users\ИМЯ_ПОЛЬЗОВАТЕЛЯ\Documents"
list
Правильный результат: после login нет сообщения об ошибке, а list показывает добавленную папку.

Linux

Ниже — подтверждённый сценарий для Ubuntu 24.04. На другом дистрибутиве название пакета ICU может отличаться.

Распакуйте архивПереместите распакованную папку в постоянное место. В примере используется ~/tcloud-backup.
Установите зависимостиДля проверенной сборки на Ubuntu 24.04 нужны локали и ICU. Без них приложение может завершиться с System.Globalization или Aborted (core dumped).
Ubuntu 24.04
sudo apt update
sudo apt install -y locales libicu74
sudo locale-gen en_US.UTF-8
Разрешить запуск и открыть консоль
cd ~/tcloud-backup
chmod +x Daotta.Desktop
./Daotta.Desktop console

Когда появится заголовок Daotta console mode и приглашение >, выполните:

Первый вход и папка
login
add "/home/ИМЯ_ПОЛЬЗОВАТЕЛЯ/Documents"
list
Замените путь в примере на настоящий. Сначала проверьте его командой ls -la "/ваш/путь". Не копируйте пример без замены имени пользователя.

Графический интерфейс

Если сборка запускается в графическом режиме, откройте программу обычным способом или без параметра console, затем перейдите на http://localhost:5000. Если страница не открывается, вернитесь к консольному варианту — он лучше показывает причину ошибки.

Первая резервная копия

Добавьте тестовую папкуИспользуйте add <path>. Путь с пробелами обязательно заключайте в кавычки.
Убедитесь, что папка сохраненаКоманда list должна показать её в списке.
Проверьте файлы и состояниеИспользуйте команды ниже. Первая загрузка может занять время.
Проверка
list
files
dashboard
watch

watch оставляет наблюдение включённым. Для выхода из него нажмите Ctrl+C. Команда exit закрывает консоль клиента.

Копирование работает, если: папка видна в list, файлы отображаются без повторяющейся ошибки, а статус не застывает на одном и том же сбое.

Если что-то не работает

Страница localhost:5000 не открывается

Проверьте, что программа всё ещё запущена. Запустите консольный режим и прочитайте первую ошибку. Не меняйте порт наугад.

Permission denied в Linux

Исправить право запуска
chmod +x Daotta.Desktop

System.Globalization или Aborted (core dumped)

На Ubuntu 24.04 установите locales и libicu74, затем повторите запуск.

Name or service not known

Это ошибка DNS или адреса API, а не доказательство неправильного пароля. Проверьте интернет и передайте администратору полный текст ошибки.

HttpClient.Timeout примерно через 100 секунд

Клиент не получил ответ сервера вовремя. Не вводите пароль снова много раз. Сохраните сообщение и обратитесь к администратору: в прошлой диагностике такой случай оказался сетевой проблемой на пути к API.

Что отправить в поддержку

  • Windows или дистрибутив и версия Linux.
  • Название файла сборки и дата получения.
  • Точная команда, после которой возникла ошибка.
  • Полный текст ошибки без пароля и токена.
Никому не отправляйте пароль, access token, содержимое хранилища паролей или приватные ключи — даже вместе со скриншотом.

Что проверено

  • Команды клиента: login, add <path>, list, files, dashboard, watch, exit.
  • Запуск Linux-клиента: ./Daotta.Desktop console.
  • Зависимости Ubuntu 24.04: locales и libicu74.
  • Локальный веб-интерфейс: http://localhost:5000.
  • Синтаксис команд Windows PowerShell и Linux shell проверен. Сам исполняемый файл в этой рабочей среде недоступен, поэтому поведение конкретной новой сборки необходимо сверять по её экрану.
