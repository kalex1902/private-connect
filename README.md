# T-Cloud Backup

Понятная инструкция для установки и использования T-Cloud Backup на Windows и Linux.

## Открыть инструкцию

- [Красиво оформленная веб-версия](https://kalex1902.github.io/private-connect/backup.html)
- [Исходный файл страницы](backup.html)

## Что внутри

- установка на Windows 10/11;
- установка на Ubuntu 24.04;
- вход в T-Cloud;
- добавление папки через `add <path>`;
- проверка через `list`, `files`, `dashboard` и `watch`;
- разбор типовых ошибок запуска, DNS и тайм-аута;
- правила безопасной передачи диагностической информации.

## Важно

Публичный URL установочного архива в доступных материалах не подтверждён. Используйте сборку, полученную напрямую от администратора T-Cloud. Не публикуйте в issue пароль, access token или приватные ключи.

Официальный визуальный стиль и логотип взяты с сайта [TriAngels / T-Guard](https://www.t-guard.net/).
