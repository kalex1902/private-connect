# T-Cloud Backup

Понятная инструкция для установки и использования T-Cloud Backup на Windows и Linux.

## Открыть инструкцию

- [Красиво оформленная веб-версия](https://kalex1902.github.io/private-connect/backup.html)
- [Исходный файл страницы](backup.html)
- [Скачать T-Cloud Backup в личном кабинете TriAngels](https://my.daotta.io/t-cloud/backup)

## Что внутри

- установка на Windows 10/11;
- установка на Ubuntu 24.04;
- вход в T-Cloud;
- добавление папки через `add <path>`;
- проверка через `list`, `files`, `dashboard` и `watch`;
- разбор типовых ошибок запуска, DNS и тайм-аута;
- правила безопасной передачи диагностической информации.

## Важно

Windows- и Linux-версии скачиваются в личном кабинете: **T-Cloud → Backup**. Для скачивания нужен активный тариф Backup. Не публикуйте в issue пароль, access token или приватные ключи.

Официальный визуальный стиль, фон и логотип взяты непосредственно с [личного кабинета TriAngels](https://my.daotta.io/t-cloud/backup).
